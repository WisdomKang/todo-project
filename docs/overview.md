# 📌 프로젝트 개요

## 프로젝트 이름

Cloud ToDo App

## 목표

간단한 할 일 리스트를 클라우드에 저장하고, 여러 디바이스(특히 스마트폰)에서 실시간 동기화하는 앱을 개발한다.

## 주요 특징

- 사용자 로그인 및 인증
- 할 일 추가/편집/삭제
- 클라우드 동기화
- 오프라인 모드 (선택적)

## 기술 스택

- **Frontend**: Flutter ( Web , Android )
- **Backend**: Go (Gin or Echo) + PostgreSQL
- **인증**: JWT / OAuth (선택 예정)
